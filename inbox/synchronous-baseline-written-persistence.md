# Use synchronous contact for baseline, writing for persistence

**Status:** Candidate

## Current wording

Use synchronous contact to establish a shared baseline when necessary.

After the baseline is clear, move recurring state, evidence, questions, and changes into written channels so the system can be audited without repeatedly consuming human attention.
