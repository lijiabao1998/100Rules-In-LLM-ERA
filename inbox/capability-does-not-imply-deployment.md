# Capability does not imply deployment

**Status:** Candidate

## Current wording

Being able to build a system is not, by itself, a reason to deploy it.

Before turning a technically feasible model into a product, ask whether its abstractions, incentives, errors, or downstream uses could create harms that exceed its informational value.
