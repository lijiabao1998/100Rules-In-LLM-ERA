# Define what would make your model lose

**Status:** Candidate

## Current wording

A fair model needs a loss condition.

Before defending an explanation, define what evidence would make you conclude that the problem is yours, the other side's, or simply noise.

---

# 中文

## 目前表述

一個公平的模型必須有明確的失敗條件。

在捍衛某個解釋以前，先定義：出現什麼證據時，你會接受問題主要在自己、主要在對方，或其實只是噪音。
