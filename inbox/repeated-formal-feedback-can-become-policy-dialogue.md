# Repeated formal feedback can evolve into policy dialogue

**Status:** Candidate

## Current wording

A one-way complaint becomes something different when the exchange is persistent, structured, evidence-based, and each official response changes the next question.

At that point, the interface is no longer only transmitting grievances. It is producing a sequence of institutional observations, clarifications, and adjustments that can function like a lightweight policy dialogue.

This does not automatically make the exchange a formal consultation or confer any official role. The distinction is functional: the conversation begins to update both the record and the next decision.

# 中文

## 目前表述

單向陳情如果變成持續、結構化、有證據，而且每一次正式回覆都會改變下一輪問題，它的性質就開始改變。

這時接口不再只是傳遞不滿，而是在持續產生制度觀察、澄清與調整，功能上會逐漸接近一種輕量的政策／政務對話。

這不代表它自動成為正式諮詢，也不代表取得任何官方身分。真正的差別在功能上：

**每一輪交流都在更新紀錄，也更新下一步決策。**
