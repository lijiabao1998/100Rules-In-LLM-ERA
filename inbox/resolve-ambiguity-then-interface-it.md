# Resolve irreducible ambiguity once, then interface it

**Status:** Candidate

## Current wording

Some relationships cannot be automated until one irreducible ambiguity is resolved synchronously.

Use the minimum necessary human interaction to establish the baseline. After that, convert recurring contact into a stateful interface: written records, status checks, change notifications, and exception escalation.

# 中文

## 目前表述

有些關係在一個不可壓縮的不確定性被當面處理以前，無法真正自動化。

用最小必要的人際互動建立基線；基線一旦成立，就把後續往來轉成有狀態的接口：書面紀錄、進度查詢、狀態變更通知與例外上拋。
