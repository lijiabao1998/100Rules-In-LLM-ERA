# Model capability can reprice old archives

**Status:** Candidate

## Current wording

A large archive can look like dead weight when humans must manually remember, reconcile, and interpret it.

As model capability improves, the same archive can change economic character. Once the records are cleaned, timestamped, de-duplicated, and linked to provenance and state changes, past friction can become a longitudinal dataset that supports better questions, comparisons, and decisions.

The important shift is not "more data is always valuable." It is:

**better models can lower the cost of turning historical complexity into usable state.**

That can give old records new option value.

# 中文

## 目前表述

當大量歷史資料只能靠人腦手動記憶、對照與解釋時，它看起來很像沉沒成本。

隨著模型能力提升，同一批資料的經濟性質可能改變。只要完成清洗、時間化、去重、來源標記與狀態變化整理，過去的摩擦就可能轉化成可比較的縱向資料集，用來提出更好的問題、做跨期比較與支援決策。

真正的變化不是「資料越多越有價值」，而是：

**更強的模型降低了把歷史複雜性轉成可用狀態的成本。**

因此，舊資料可能重新獲得新的選擇權價值。
