# Treat repeated manual work as a systems signal

**Status:** Candidate

## Current wording

When a task is repeated often enough to become predictable, continued manual execution is usually a signal to improve the system rather than a reason to judge the operator.

Automate the stable path; move human attention to validation, exceptions, and decisions.

---

# 中文

## 目前表述

當一項工作重複到已經足夠可預測時，持續手工執行通常代表系統該升級了，而不是操作的人「不夠聰明」。

把穩定路徑自動化，將人的注意力移到驗證、例外與決策。
