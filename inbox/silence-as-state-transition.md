# Silence can be a state transition

**Status:** Candidate

## Current wording

Silence becomes actionable when a response was reasonably due.

A missing reply is not proof of motive, but it can be a new procedural state that justifies a status inquiry or follow-up.

## 目前表述

當一個回覆在合理程序上已經應該出現時，沉默本身就會變成可處理的新狀態。

沒有回覆不能證明對方的動機，但可以構成新的程序節點，足以支持狀態查詢或後續追問。
