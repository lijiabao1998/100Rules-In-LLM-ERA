# Human workflows often reveal the agent architecture first

**Status:** Candidate

## Current wording

Before automating a workflow, look for the interaction pattern that already works between people.

Status reporting, explicit uncertainty, bounded approval, scoped execution, verification, and exception escalation are often the real architecture. Agents merely compress and accelerate that structure.
