# Use zero-trust interfaces without hostile attribution

**Status:** Candidate

## Current wording

When an interface has repeatedly produced ambiguity, inconsistency, or avoidable risk, treat the interface as untrusted by default.

Require verification, written records, minimal disclosure, and explicit boundaries. But do not turn the security posture into a claim that every individual is malicious.

# 中文

## 目前表述

當一個接口反覆產生模糊、前後不一致或可避免的風險時，可以預設把這個接口視為不可信。

要求驗證、書面留痕、最小必要披露與明確邊界；但不要把這種安全姿態直接升級成「每一個人都具有惡意」的事實判斷。
