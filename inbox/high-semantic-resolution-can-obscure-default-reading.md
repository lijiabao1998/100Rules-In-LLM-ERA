# High semantic resolution can obscure default reading

**Status:** Candidate

## Current wording

More linguistic precision does not always improve social interpretation.

When analysis becomes too fine-grained, every phrase can branch into many plausible meanings. Ordinary readers usually do not resolve language at that depth; they rely on tone, context, politeness markers, conversational defaults, and the most likely intent.

A useful check is therefore:

**What would an ordinary cooperative reader infer first?**

High-resolution interpretation is valuable for edge cases, but it should not replace the default-reader model.

# 中文

## 目前表述

語言解析能力越高，不代表社交判讀一定越準。

當分析粒度過細時，一句普通表達可能被展開成很多語義分支；但一般人通常不會解析到這個深度，而是依靠語氣、上下文、禮貌標記、對話慣例與最可能的意圖來理解。

因此可以加入一個校準問題：

**一個普通、合作性的讀者，第一眼最可能怎麼理解？**

高解析度適合處理邊界情況，但不應取代「普通讀者模型」。
