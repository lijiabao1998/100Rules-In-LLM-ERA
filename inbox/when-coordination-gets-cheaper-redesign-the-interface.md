# When coordination gets cheaper, redesign the interface

**Status:** Candidate

## Current wording

Many conflicts persist because information, verification, and escalation used to be expensive.

When better tools make these functions cheap—persistent records, automated state checks, searchable history, clear routing, and fast document generation—the optimal strategy changes.

Do not keep paying the old coordination cost.

Redesign the interface so ambiguity is resolved once, state persists, and future interaction becomes low-cost and auditable.

# 中文

## 目前表述

很多衝突之所以反覆存在，是因為過去資訊取得、核對、留痕與升級處理都很昂貴。

當新的工具把這些成本壓低——持久紀錄、自動狀態查詢、可搜尋歷史、清楚路由與快速文件生成——最佳策略也會跟著改變。

不要繼續支付舊時代的協調成本。

重新設計接口：模糊問題只解一次、狀態可以持續、後續互動低成本且可稽核。
