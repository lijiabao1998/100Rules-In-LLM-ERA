# Real-time model updating is a separate capability

**Status:** Candidate

## Current wording

Knowing more about the world is not the same as updating a model quickly when the world changes.

A stronger operating loop is:

observation → competing hypotheses → cheapest discriminating probe → new evidence → model update.

The gain comes from reducing the lag between reality and the model, not merely from accumulating more prior knowledge.

# 中文

## 目前表述

更了解世界，和能在世界變化時快速更新模型，是兩種不同能力。

更強的運作迴路是：

觀察 → 競爭假設 → 最便宜的區分性探針 → 新證據 → 模型更新。

真正的提升，不只是累積更多既有知識，而是縮短「現實發生變化」到「模型完成修正」之間的延遲。
