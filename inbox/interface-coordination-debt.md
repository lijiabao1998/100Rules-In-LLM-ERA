# Unresolved ambiguity compounds into interface debt

**Status:** Candidate

## Current wording

When an interface operates too long without shared state, unresolved assumptions accumulate as coordination debt.

Future interactions then spend resources servicing old ambiguity before they can process the new task.

A clean baseline can act as a cutover point: preserve the history, but stop forcing every new interaction to repay it.

# 中文

## 目前表述

當一個接口長期缺乏共同狀態時，未解決的假設會累積成協調債務。

之後每一次新互動，都必須先花資源償還舊的不確定性，才能處理真正的新事情。

建立一條乾淨基線，可以成為切換點：歷史仍然保留，但不再要求每一次新互動都替過去還債。
