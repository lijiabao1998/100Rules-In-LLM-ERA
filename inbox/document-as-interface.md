# A document can be the interface

**Status:** Candidate

## Current wording

Do not integrate an interface before proving that a document cannot close the loop.

If a standardized document can carry state, evidence, request, receipt, and next action, the document is already an interface.

---

# 中文

## 目前表述

在證明「文書無法閉環」以前，不要急著做更重的接口整合。

如果一份標準化文書已經能承載狀態、證據、請求、收受紀錄與下一步行動，那麼文書本身就已經是一個接口。
