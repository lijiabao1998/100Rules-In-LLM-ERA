# Analysis scales when the data source becomes callable

**Status:** Candidate

## Current wording

Many recurring analysis tasks stop being document work once the source system becomes callable.

If an agent can query the authoritative data through a stable interface, the reusable asset is no longer the report itself but the pipeline: retrieve, normalize, interpret, compare, validate, and render.

# 中文

## 目前表述

很多重複性的分析工作，一旦資料來源可以被直接調用，就不再主要是「做文件」。

當 Agent 能透過穩定接口查詢權威資料源時，真正可複用的資產不再是報表本身，而是整條流程：取數、正規化、解讀、比較、驗證與輸出。
