# Feedback turns procedure into instrumentation

**Status:** Candidate

## Current wording

A repetitive process is not necessarily cognitively expensive if each cycle returns observable feedback.

When an interface produces timestamps, responses, wording changes, delays, decisions, and exceptions, the process can become an instrument for learning rather than a source of pure friction.

The key distinction is not bureaucracy versus no bureaucracy. It is **opaque repetition versus observable iteration**.

# 中文

## 目前表述

重複流程本身未必昂貴；如果每一輪都會回傳可觀測的反饋，它就能從摩擦來源變成學習工具。

當一個接口持續產生時間點、回覆、措辭變化、延遲、決定與例外時，流程本身就可以成為量測制度運作的儀器。

真正重要的差別，不是「有沒有官僚流程」，而是：

**不透明的重複，還是可觀測的迭代。**
